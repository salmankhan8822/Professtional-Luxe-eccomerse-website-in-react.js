# 🛍️ Luxe — Modern Clothing E-Commerce Website

**Luxe** is a fully responsive clothing e-commerce web application built with **React.js** as a hands-on project to strengthen and practice core React concepts. It simulates a real-world online fashion store — from browsing products to managing a cart and completing checkout — while showcasing clean UI design with **Bootstrap**.

---

## 📌 About the Project

Luxe was built as a personal learning project to move beyond React tutorials and apply core concepts in a real, multi-page application. The goal was to design and build a complete clothing store experience — product listings, product details, a shopping cart, and a checkout flow — using only React and Bootstrap for styling.

This project reflects my growth as a frontend developer, from structuring components and managing state, to handling navigation and building a consistent, professional UI.

---

## ✨ Features

- 🏠 **Home Page** — Hero section and featured products to welcome visitors
- 🧥 **Product Listing Page** — Browse all clothing items with images, prices, and details
- 🔍 **Product Details Page** — View individual product information dynamically
- 🛒 **Shopping Cart** — Add, update, and remove items with live cart updates
- 💳 **Checkout Page** — Review order summary before completing a purchase
- 📱 **Fully Responsive Design** — Optimized for mobile, tablet, and desktop using Bootstrap
- ⚡ **Component-Based Architecture** — Reusable, maintainable UI components
- 🧭 **Client-Side Routing** — Seamless page navigation without full reloads

---

## 🧠 React.js Concepts I Learned & Practiced

Building Luxe helped me gain hands-on experience with the following React concepts:

- **Component Architecture** — Breaking the UI into small, reusable, and composable components
- **Props** — Passing data between parent and child components
- **State Management** — Using `useState` to manage dynamic data like cart items and product selection
- **Side Effects** — Using `useEffect` to handle data loading and side effects
- **Context API** — Sharing global state (like cart data) across components without prop drilling
- **React Router (`react-router-dom`)** — Implementing multi-page navigation (`Home`, `Products`, `Product Details`, `Cart`, `Checkout`) with dynamic routes for individual products
- **Conditional Rendering** — Displaying UI elements based on state (e.g., empty cart message, loading states)
- **List Rendering & Keys** — Efficiently rendering product lists using `.map()` and unique keys
- **Controlled Components** — Managing form inputs for checkout and cart updates
- **Lifting State Up** — Sharing state between sibling components through common parent components
- **Event Handling** — Handling user interactions like adding/removing items from the cart
- **Component Reusability** — Building shared components (Navbar, Product Card, Footer, Button) used across multiple pages

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/your-username/luxe.git
cd luxe
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm start
```

The app will run at `http://localhost:3000`
